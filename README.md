## How I work

I work with AI coding agents every day, Claude Code and Codex. I build a harness around them: a set of rules and steps the agents must follow. Every piece of work starts with an issue, the agent works on that issue in its own branch, and another agent reviews the change before it is merged. This started as [Software Factory](https://github.com/stabem/software-factory).
